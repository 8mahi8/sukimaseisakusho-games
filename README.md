### このメッセージは送信されていません｜V0.1

スマートフォンに残る2通の未送信下書きを仮に送信し、他人のチャット履歴が変わる様子を調べる短編ミステリー。

- [ゲーム本体：index.html](prototypes/message-not-sent/index.html)
- ブラウザ試作（5〜10分想定。実プレイヤーによる所要時間は未計測）
- 2つの下書き、4つの再構成、3会話、履歴差分、推理問題、エンディング1種
- HTMLファイル1つだけで動く。インストール、外部ライブラリ、外部通信、セーブ、個人情報収集なし
- 現在の試作はPCブラウザでの体験を優先。スマートフォン幅のUIテストは済んだが、iPhoneなど実機でのローカルHTML起動可否は未検証

**遊び方：** 上記index.htmlをGitHubで開き、右上の「Download raw file」から保存。PCのChrome/Edge等で開き、下書きを送る→チャットを調べる→別パターンでも送る→2パターンを「原本と比較」→23:17の通知の詳細を調べる→結論を提出する。

**重要：** Private repo内のソースを外部へ無断公開しない。GitHub Pagesの公開設定はしない。BOOTH販売・商品登録・価格・公開は本人の最終判断。V0.1は内部プロトタイプであり、商品品質の独立レビューや有料需要は未検証。
